# Security

Vibe Product OS is currently an internal alpha. Do not submit secrets, private signing keys, credentials, regulated data, or confidential project evidence through a public issue.

Security findings must be routed privately to the Product OS Authority using an Authority-approved channel. The repository and npm package must never contain private signing keys.

Checksums establish byte identity only. Publisher identity requires the governed digital signature and key-custody evidence defined by `AUTH-COND-001`.
