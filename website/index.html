One methodology. Three depths.

Start with the lightest useful profile. Increase depth only where complexity, risk, regulation, or coordination requires it.

P1 Lean

P1 bounded delivery

For focused work that still needs explicit decisions, traceability, evidence, and handoff.

P2 Standard

P2 recommended starting point

For real product teams, multi-agent collaboration, reviewable artifacts, gates, and controlled change.

P3 Comprehensive

P3 specialist coverage

For regulated, enterprise, high-risk, multi-team, or contract-heavy delivery.
